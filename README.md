# Learning How to Learn

## Description

This project is a responsive landing page about learning techniques and methods. It features semantic HTML, CSS animations, and BEM methodology.

## Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Styling and animations
- **BEM Methodology**: Block Element Modifier naming convention
- **CSS Flexbox**: Layout system
- **CSS Animations**: Rotating square and triangle elements
- **Google Fonts**: Inter and Noto Serif font families

## Features

- CSS keyframe animations
- Embedded video content
- Contact form
- BEM file structure organization

## Future Improvements

- Add responsive breakpoints for mobile devices
- Implement JavaScript functionality
- Add more interactive elements
